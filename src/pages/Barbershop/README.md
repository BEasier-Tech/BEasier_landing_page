# Landing Page 7. **Preços**: Grid com os 3 planos principais e destaque para o mais popular
8. **Teste Grátis**: 10 dias de teste gratuito sem cartãoBarbearia

## Visão Geral

Esta é uma landing page especializada voltada para o segmento de barbearias, criada com base na estrutura existente do projeto Gestão Boa e inspirada no layout do site de referência fornecido.

## Características da Página

### Estrutura e Layout
- **Hero Section**: Título impactante com call-to-action principal
- **Vídeo de Demonstração**: Mostra o sistema em funcionamento
- **Seção de Problemas**: Lista dores específicas de barbeiros desorganizados
- **Seção de Soluções**: Mostra como o sistema resolve cada problema
- **Depoimentos Reais**: Testemunhos autênticos de clientes atuais
- **Funcionalidades**: Grid com principais recursos do sistema
- **Preços**: Planos com valores reais da Gestão Boa
- **Garantia**: Política de satisfação
- **CTA Final**: Última chamada para ação

- **Plano Básico**: R$ 64,90/mês - 1 usuário
